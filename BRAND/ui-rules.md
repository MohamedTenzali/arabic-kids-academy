# Arabic Kids Academy UI Rules

1. Use rounded corners everywhere.
2. Use soft shadows only.
3. No hard black borders.
4. Large touch targets for children.
5. Use lots of spacing.
6. Keep layouts simple.
7. Use playful but calm colors.
8. Do not overload the screen.
9. Consistent card design.
10. Child-friendly navigation.
11. Use subtle animations only.
12. Keep educational focus.
